# China Customs customs regime names

A dataset containing all customs regime names used by China Customs in
English and Chinese, including their codes.

## Usage

``` r
cc_regimes
```

## Format

A data frame with 20 rows and 3 variables:

- code:

  customs regime code

- en:

  English customs regime name

- zh:

  Chinese customs regime name

## Source

<http://stats.customs.gov.cn/indexEn>
