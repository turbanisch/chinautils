# Package index

## Read China Customs data

Read and clean trade data exported from China Customs, handling
encoding, mixed English/Chinese columns and arbitrary column order.

- [`cc_read_csv()`](https://turbanisch.github.io/chinautils/reference/cc_read_csv.md)
  : Read and Clean Trade Data From China Customs

## Harmonize names

Convert Chinese country and province names to standardized codes.

- [`countryname()`](https://turbanisch.github.io/chinautils/reference/countryname.md)
  : Harmonize Country Names in Chinese
- [`provincename()`](https://turbanisch.github.io/chinautils/reference/provincename.md)
  : Harmonize Province Names

## Bundled datasets

Reference tables used by the functions above and useful on their own,
e.g. to re-attach clean descriptions to customs codes.

- [`country_dict`](https://turbanisch.github.io/chinautils/reference/country_dict.md)
  : Concordance table of country names and codes.
- [`province_dict`](https://turbanisch.github.io/chinautils/reference/province_dict.md)
  : Concordance table of province names and codes.
- [`cc_commodities`](https://turbanisch.github.io/chinautils/reference/cc_commodities.md)
  : China Customs commodity codes
- [`cc_partners`](https://turbanisch.github.io/chinautils/reference/cc_partners.md)
  : China Customs trading partner names
- [`cc_regimes`](https://turbanisch.github.io/chinautils/reference/cc_regimes.md)
  : China Customs customs regime names
- [`cc_variable_names`](https://turbanisch.github.io/chinautils/reference/cc_variable_names.md)
  : China Customs variable names
